# Perry Desktop — витрина (Figma)

Актуальный React + Vite storefront после полной переписи под Figma (~22 экрана).

Старый Razor-фронт `Perry.Web` из этого репозитория **удалён**.

## Запуск

Из корня репозитория: `start-desktop.cmd` или ярлык **Perry Desktop**.

Вручную:

```bash
cd frontend
npm install
npm run dev
```

→ http://localhost:3000  

Нужен Product API на http://localhost:5272 (`start-api.cmd`).
