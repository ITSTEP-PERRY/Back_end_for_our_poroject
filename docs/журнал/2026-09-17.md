## 1. Категории (API + домен)

Закрыт пробел по полям создания/обновления категории.

### Entity `Category`
- `Description` — описание категории
- `ImageUrl` — картинка (главная / меню)
- `IconUrl` — иконка
- `IsActive` — активность (уже было; участвует в Create/Update)

### Миграция
- `20260917155439_AddCategoryDescriptionAndIconUrl` — колонки `Description`, `IconUrl` (+ конфигурация `ImageUrl` в snapshot)

### `POST/PUT /api/categories`
Тело `CategoryWriteRequest`:
- `name`, `slug?`, `description?`, `imageUrl?`, `iconUrl?`
- `parentCategoryId?`, `sortOrder`, `isActive`

### Ответы списка/дерева
Возвращают `description`, `imageUrl`, `iconUrl`, `isActive`, `sortOrder`, `parentCategoryId`.

### Админка
- Razor: `Pages/Admin/Categories.cshtml` (+ tree item)
- React: `AdminCategoriesPage` — форма с description / imageUrl / iconUrl / IsActive

## 2. Каталог товаров (API)

`GET /api/products` расширен под Figma Product List V2 (`722:2370`):

**Фильтры query:**
- `brands[]`, `fabrics[]`, `sizes[]`, `colors[]`
- `minPrice`, `maxPrice`, `minRating`
- `categoryId`, `search`, `sort`, `page`, `pageSize`

**Ответ дополнен `facets`:**
- `brands`, `fabrics`, `sizes`, `colors` — опции для сайдбара фильтров

Fabric / Size / Color берутся из атрибутов товара (`Fabric type`, `Size`, `Color`).

## 6. React storefront (`perry-front`)

Порт витрины 1:1 со стилями Razor/`site.css` + auth.css, без Ant Design ConfigProvider на витрине.

### Слои
| Путь | Назначение |
|------|------------|
| `src/styles/storefront.css`, `auth.css` | Визуал Figma/Razor |
| `src/api/` | client, types, categories/products/auth/orders |
| `src/app/` | router, AuthContext, CartContext, RequireAuth |
| `src/pages/` | Home, Products, Product, Cart, Orders, Legal, Auth, Admin |
| `src/widgets/` | AppShell, AuthShell, ProductCard, auth fields |
| `public/icons`, `public/images` | Ассеты макета |

### Страницы / маршруты
- `/` — Home (hero, категории, Trending, Sale, CTA «Abundance of goods»)
- `/products` — фильтры Brand / Fabric type / Size / Color / Price / Customer reviews (fallback-списки из Figma)
- `/products/:id` — gallery, buy-box (Delivery, Payment, Security, Returns), reviews, «You may also like», «Best sellers in …»
- `/cart`, `/orders`, `/profile`
- `/terms`, `/privacy`, `/license`
- Auth: `/login`, `/register`, `/forgot-password`, `/verify-code`, `/reset-password`, `/finishing-touches`, `/auth/success`
- Admin: `/admin/*`

### Auth UX (как Figma 16–25)
- 3 неудачных логина → Send code
- Register → Finishing touches → Congratulations
- Forgot → Reset password → Congratulations

### Vite
- proxy `/api`, `/uploads` → `:5272`
- `server.watch.ignored`: `My_Amazon2`, `Back_end…` (фикс падения EBUSY при `dotnet build`)
