## 1. Почему DummyJSON

| Вариант | Вердикт |
|---------|---------|
| **DummyJSON** | ✅ ~194 товара, `thumbnail` + `images[]`, без API-ключа, стабильный CDN |
| Fake Store API | мало (20 шт.) |
| Unsplash / Picsum | не товарные фото / нужны ключи или hotlink-прокси |
| Хостинг с Amazon и т.п. | ❌ по лицензии нельзя |

Endpoint: `GET https://dummyjson.com/products?limit=0`

## 2. Как подтянули и разложили по разделам

Всё в `Perry.Infrastructure/Persistence/DbSeeder.cs` (запуск при `ASPNETCORE_ENVIRONMENT=Development`).

### 2.1 Каталог

1. При `SeedAsync` вызывается `LoadDummyCatalogAsync()`:
   - сначала сеть → DummyJSON API;
   - если офлайн — встроенный snapshot `dummyjson-products.json` (EmbeddedResource, ~194 записи: id, категория, title, brand, price, images).
2. Парсер понимает и live-ответ `{ products: [...] }`, и локальный массив.

### 2.2 Разделы (маппинг DummyJSON → Perry)

| DummyJSON category | Категория Perry (slug) |
|--------------------|-------------------------|
| smartphones, tablets, mobile-accessories, laptops | `pcs-accessories` |
| mens-shirts, tops | `t-shirts` |
| womens-dresses | `casual-womens-clothing` |
| shoes / sports | `fashion` |
| bags / watches / jewellery / sunglasses | `womens-fashion` |
| beauty, fragrances, skin-care | **`beauty`** (новый раздел) |
| furniture, home-decoration, kitchen, groceries | **`home-kitchen`** (новый раздел) |
| vehicle, motorcycle | `electronics` |

`EnsureDummyJsonCategoriesAsync` создаёт Beauty и Home & Kitchen, если их ещё нет.

### 2.3 Импорт товаров

`EnsureDummyJsonProductsAsync`:

- SKU = `DJ-{id:D3}` (идемпотентно — повторный старт не дублирует);
- имя, бренд, цена, описание, рейтинг, сток — из DummyJSON;
- галерея `ProductImages` — URL с `cdn.dummyjson.com` (primary = первое фото).

### 2.4 Старые демо-товары и категории

`EnsureShopLooksAliveAsync`:

- picsum / unsplash / пустые URL → пакет DummyJSON по теме товара;
- плитки категорий (`ImageUrl` / `IconUrl`) тоже на CDN DummyJSON;
- отзывы с picsum-миниатюрами → thumbnail товара.

API уже отдаёт абсолютные `http…` URL как есть (`ApiHelpers.GetImageUrl`) — менять фронт не пришлось.

### 2.5 Проверка после сида

- `GET /api/products` → **~206** товаров;
- `imageUrl` с хоста `cdn.dummyjson.com`;
- категории: Electronics, Fashion, Beauty, Home & Kitchen.

## 5. Как воспроизвести

1. Postgres (Docker) или строка БД в `.env`.
2. `ASPNETCORE_ENVIRONMENT=Development` → при старте Perry.Api сидер сам прогонит DummyJSON.
3. Витрина: http://localhost:3000 · Mobile: http://localhost:8081 · API: http://localhost:5272/swagger

Повторный старт безопасен: `DJ-*` не плодятся, плейсхолдеры уже заменены на DummyJSON.
