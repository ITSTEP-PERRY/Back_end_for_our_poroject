## 1. Translate на отзывах

**Было:** кнопка Translate — заглушка (`demo action`).

**Сделано:**
- Клиент: `frontend/src/utils/translateToUk.ts` — MyMemory API `en|uk`
- На карточке отзыва: перевод title + body, подпись *Translated to Ukrainian*, повторный клик — *Show original*
- Зеркало логики на mobile PDP

---

## 2. Фото в Create review

**Было:** «+» открывал `prompt` с URL; фото не уходили в API / ломались.

**Сделано:**
- Выбор файла с диска (JPEG/PNG/WebP/GIF, до 5 MB), превью в модалке
- При Create — `imageUrls` в `POST /api/reviews`
- Backend: data-URL слишком длинный для `Url(1000)` → сохранение в `wwwroot/uploads/` коротким путём (`DiskStorageService.SaveDataUrl`)
- Раздача статики: явный `UseStaticFiles` на `/uploads`
- Правило **один отзыв на товар** сохранено (409 при дубликате)

---

## 3. Checkout: страна → города, оплата

**Было:** City пустой, пока не выбран State; короткий список городов.

**Сделано:**
- Список городов подгружается сразу после выбора Country (опционально фильтр по State)
- Украина — ~50 городов; расширены US / CA / UK / DE / PL
- Card: форматирование номера/срока, проверка Luhn, демо-карта `4111 1111 1111 1111` (без реального charge)
- Place order → `ordersApi.checkout` с `paymentType` Cash/Card
