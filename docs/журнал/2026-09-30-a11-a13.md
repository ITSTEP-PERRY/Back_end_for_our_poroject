## Фикс Users: Network error (CORS)

**Симптом:** `/admin/users` → `Network error — Users API unreachable`.

**Причина:** в `.env` стояли абсолютные `VITE_*_API_URL=https://…azure…`. Браузер ходил в Azure напрямую → CORS → `fetch` падал как network error. Сервис при этом живой.

**Исправление (FE):**

1. `src/api/client.ts` — в DEV всегда same-origin proxy (`/auth-api`, `/users-api`), абсолютный Azure URL игнорируется.
2. `.env.example` — для локалки относительные `/auth-api`, `/users-api`.
3. Локальный `.env` (не в git) — те же relative paths.

**Как пользоваться Users:** логин Auth Admin (Azure JWT), не локальный `Admin`/`Admin`. Локальный Admin открывает только Product API.
