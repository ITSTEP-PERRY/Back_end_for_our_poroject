# #95 — ответ Auth (28.09 вечер)

Получен конфиг Auth (личные сообщения). Действия в Product API:

1. `Jwt:SigningSecret` / `Jwt:Key` → локальный `.env` (не в git).
2. `SkipSignatureValidation` → `false`.
3. Issuer/Audience → `Perry.AuthService` / `Perry.Client`.
4. Internal: `POST /internal/auth/token` (`serviceName=local-service`); plaintext credential **ещё нужен** (в дампе только CredentialHash).
5. Docs: [AUTH-INTEGRATION.md](./AUTH-INTEGRATION.md) · Trello [#95](https://trello.com/c/T28F0b7e).

Не используем в Product и не коммитим: Resend, Supabase Auth DB, VerificationCodes, InternalJwt SigningSecret.
