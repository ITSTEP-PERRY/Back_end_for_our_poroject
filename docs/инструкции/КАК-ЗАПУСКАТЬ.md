# Как запускать Perry

Краткая инструкция: **десктопная витрина** (Vite) и **мобильная версия** (Expo).

Корень репозитория: `D:\Perry` (или ваш клон).

---

## Две иконки (самое быстрое)

| Ярлык | Скрипт | URL |
|-------|--------|-----|
| **Perry Desktop** | `start-desktop.cmd` | http://localhost:3000 |
| **Perry Mobile** | `start-mobile.cmd` | http://localhost:8081 |

Создать / обновить ярлыки в корне репо и на рабочем столе:

```powershell
powershell -ExecutionPolicy Bypass -File .\Install-Perry-Shortcuts.ps1
```

Алиасы: `Запуск-Desktop.cmd` · `Запуск-Mobile.cmd`.

---

## Что нужно заранее

| Требование | Зачем |
|------------|--------|
| **Node.js** 18+ (npm) | Desktop + Mobile |
| **Perry.Api (Product)** на порту **5272** | Каталог, корзина, заказы, wishlist |
| Auth | Azure Auth Service (проксируется с FE) |

Проверка Product:

```text
http://localhost:5272/api/health
```

Без API витрина откроется, но товары/корзина не загрузятся.

Auth для desktop идёт через Vite-прокси `/auth-api` → Azure.  
Для mobile Expo Web — через Metro-прокси `/auth-api` и **`/api` → Perry.Api :5272** (тот же Product backend, что у desktop).

Нативный Expo (Android/iOS) ходит на Product по `EXPO_PUBLIC_PRODUCT_URL` напрямую.

---

## Быстрый старт — ярлыки на рабочем столе

После установки зависимостей можно просто дважды кликнуть:

| Ярлык | Что запускает | URL |
|-------|----------------|-----|
| **Perry Desktop** | Vite-витрина | http://localhost:3000 |
| **Perry Mobile** | Expo Web | http://localhost:8081 |

В корне репо лежат те же скрипты:

- `Запуск-Desktop.cmd`
- `Запуск-Mobile.cmd`

Окно консоли **не закрывайте**, пока работаете с приложением (Ctrl+C — остановить).

## 1. Десктопное приложение (web-витрина)

### Способ A — ярлык / cmd

1. Дважды кликните **Perry Desktop** (или `Запуск-Desktop.cmd`).
2. Дождитесь строки вроде `Local: http://localhost:3000/`.
3. Откройте в браузере: **http://localhost:3000**

### Способ B — вручную в терминале

```bash
cd D:\Perry
npm install          # один раз, если ещё нет node_modules
npm run dev
```

Откройте **http://localhost:3000**.

Порт задан в `vite.config.ts` (`server.port: 3000`).  
Запросы `/api` проксируются на `http://localhost:5272`.

### Что это

React + Vite витрина покупателя (и admin-маршруты в том же приложении).  
Код: папка `src/`.

---

## 2. Мобильная версия (Expo)

### Способ A — ярлык / cmd

1. Убедитесь, что Product API слушает **:5272**.
2. Дважды кликните **Perry Mobile** (или `Запуск-Mobile.cmd`).
3. Откройте **http://localhost:8081** (Expo Web).

### Способ B — вручную в терминале

```bash
cd D:\Perry\mobile
copy .env.example .env   # если .env ещё нет
npm install              # один раз
npx expo start --web --port 8081
```

Или:

```bash
npm run web
```

(по умолчанию Expo выберет свободный порт; ярлык явно использует **8081**).

### Файл `.env` (mobile)

Пример для локального демо / браузера / iOS Simulator:

```env
EXPO_PUBLIC_PRODUCT_URL=http://localhost:5272
EXPO_PUBLIC_AUTH_URL=https://perry-auth-service.orangeplant-910928aa.swedencentral.azurecontainerapps.io
EXPO_PUBLIC_APP_ENV=development
```

| Где крутится приложение | `EXPO_PUBLIC_PRODUCT_URL` |
|-------------------------|---------------------------|
| Expo Web / браузер на этом ПК | `http://localhost:5272` |
| iOS Simulator | `http://localhost:5272` |
| Android Emulator | `http://10.0.2.2:5272` |
| Телефон в той же Wi‑Fi | `http://<IP-вашего-ПК>:5272` |

После смены `.env` перезапустите Expo (лучше с очисткой кэша):

```bash
npx expo start --web --port 8081 --clear
```

### Другие режимы Expo

```bash
cd D:\Perry\mobile
npm start          # меню Expo
# затем: w — web, a — Android, i — iOS
```

Код мобилки: папка `mobile/`.  
Подробнее по API/UI: [РЕШЕНИЕ-MOBILE-С-КОДОМ.md](./РЕШЕНИЕ-MOBILE-С-КОДОМ.md).

## 3. Типичный порядок на день разработки

1. Запустить **Perry.Api** → `:5272`.  
2. Запустить **Desktop** и/или **Mobile** (ярлыки или cmd).  
3. Desktop: http://localhost:3000  
4. Mobile: http://localhost:8081  

Можно держать оба фронта одновременно — порты разные (3000 и 8081).

---

## 4. Частые проблемы

| Симптом | Что сделать |
|---------|-------------|
| Нет товаров / ошибка сети | Проверить `http://localhost:5272/api/health` |
| Auth «недоступен» в браузере | На desktop/mobile web нужен proxy; перезапустить Vite/Expo после правок `metro.config.js` / `vite.config.ts` |
| Порт 8081 занят | Закрыть старый Expo или сменить порт в команде |
| `ENOSPC` / нет места на диске C: | Освободить место; TEMP для mobile-скрипта направлен на `D:\Perry\.tmp` |
| Пустой экран после смены `.env` | `npx expo start --clear` |
| Ярлык не находит npm | Установить Node.js и переоткрыть ярлык (PATH) |
