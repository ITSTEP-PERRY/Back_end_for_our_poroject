# Как запускать Perry (этот репозиторий)

**Только React-витрина** (`frontend/`, Vite) и **Expo Mobile** (`mobile/`).  
Старый Razor `Perry.Web` **удалён** — не запускайте `dotnet run --project src/Perry.Web` (проекта больше нет).

Репозиторий: https://github.com/Teslyar75/My_Amazon2

---

## Самый быстрый способ

1. `git clone` / `git pull` **этого** репо.  
2. Дважды кликните `Create-Shortcuts.cmd`.  
3. Порядок: **Perry API** → **Perry Desktop** (React `:3000`) и/или **Perry Mobile** (`:8081`).

| Ярлык | Скрипт | Что | URL |
|-------|--------|-----|-----|
| Perry API | `start-api.cmd` | Postgres + API | http://localhost:5272/swagger |
| Perry Desktop | `start-desktop.cmd` | **React** в `frontend/` | http://localhost:3000 |
| Perry Mobile | `start-mobile.cmd` | Expo в `mobile/` | http://localhost:8081 |

Подробнее по API: [КАК-ЗАПУСКАТЬ-API.md](./КАК-ЗАПУСКАТЬ-API.md)

---

## Вручную (React Desktop)

```bash
# терминал 1 — API
cd My_Amazon2
start-api.cmd
# или: docker compose up -d postgres
#      dotnet run --project src/Perry.Api --launch-profile http

# терминал 2 — React
cd My_Amazon2/frontend
npm install
npm run dev
```

Открыть **http://localhost:3000** (не :5122 — это был старый Razor).

---

## Mobile

```bash
cd My_Amazon2/mobile
copy .env.example .env
npm install
npx expo start --web --port 8081
```

Или `start-mobile.cmd` / ярлык **Perry Mobile**.
