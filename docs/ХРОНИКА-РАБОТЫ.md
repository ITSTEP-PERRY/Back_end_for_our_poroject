## Этап 0 · Основа решения

**Цель:** бэкенд зоны товаров + общая БД.

- Solution: `Perry.Domain` · `Perry.Infrastructure` · `Perry.Api` · `Perry.Web`
- Сущности: Category (дерево), Product, Images, Attributes, Reviews, Cart, Orders; **Users вынесены в Auth Service (#94)**
- EF Core + LocalDB `Perry`, seed, soft-delete
- Паттерны из homework (админ / корзина / заказы) перенесены в Perry
- Ребрендинг DuSoleil → **Perry**

## Этап 1 · Auth покупателя (Razor → затем React)

**Последовательность экранов по макету:**

1. Welcome back (Login)  
2. Create account (Register)  
3. Finishing touches (имя)  
4. Congratulations  
5. VerifyCode (после 3 неудачных входов)

**Важно для демо:** SMTP по умолчанию **stub** — код/ссылка в логе API, не на Gmail. Речь: [РЕЧЬ-SMTP-ДЕМО.md](./РЕЧЬ-SMTP-ДЕМО.md). Включить почту: [SMTP-НАСТРОЙКА.md](./SMTP-НАСТРОЙКА.md). Сценарии: [ВОССТАНОВЛЕНИЕ-ПАРОЛЯ.md](./ВОССТАНОВЛЕНИЕ-ПАРОЛЯ.md).

JWT для API: access token выдаёт **Perry Auth Service** (Влада); Product API только валидирует Bearer и читает `UserId` (#94/#95). Локальный `/api/auth` в Product удалён.

```bash

cd My_Amazon2   # или клон Back_end
dotnet run --project src/Perry.Api --launch-profile http

cd perry-front  # D:\Perry
npm install
npm run dev
# http://localhost:3000
```

## Задача команде (фронт): две линии + архитектура Яны

На `perry-front` после merge часто лежат:
1. **Рабочая (A)** — Figma-порт (`App` → `router`, `styles/*`, `pages/*.tsx`) — это демо `:3000`.  
2. **Линия Яны (B)** — Ant Design / Redux (`Components/`, `pages/HomePage/`, ветка `alex`) — роутер порта не использует.  
3. **Эталон admin (C)** — отдельный репо [perry-admin-front](https://github.com/ITSTEP-PERRY/perry-admin-front).

Коллегам «тяжело копать», потому что школы разные. Нужно выбрать source of truth. Чеклист: [СВЕСТИ-ДВЕ-ЛИНИИ.md](./СВЕСТИ-ДВЕ-ЛИНИИ.md) · вопросы: [ВОПРОСЫ-КОМАНДЕ.md](./ВОПРОСЫ-КОМАНДЕ.md) · отчёт: [ОТЧЁТ-2026-09-26.md](./ОТЧЁТ-2026-09-26.md).
