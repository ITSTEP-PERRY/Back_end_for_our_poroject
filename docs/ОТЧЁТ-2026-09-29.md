## 2. Reviews — Invalid column `Reported`

Симптом: `GET /api/reviews` → SQL `Invalid column name 'Reported'`.

Причина: таблица `ProductReviewGrades` без колонки при уже «применённой» миграции.

Исправление в `DbSeeder.EnsureReviewGradeReportedColumnAsync` — идемпотентный SQL:

```sql
IF COL_LENGTH(N'dbo.ProductReviewGrades', N'Reported') IS NULL
  ALTER TABLE ... ADD Reported bit NOT NULL DEFAULT (0);
```

Вызывается из `MigrateAsync` / `SeedAsync` при старте API.

## 3. Локальный Admin для React (`:3000`)

Razor `/Admin/Login` — stub (вход через Auth + React).

Для локальной разработки Product без Azure Auth:

| Метод | Путь | Примечание |
|-------|------|------------|
| `POST` | `/api/dev/admin-login` | body `{ login, password }` → `Admin`/`Admin` |
| `GET` | `/api/dev/me` | `[Authorize]` |
| `GET` | `/api/dev/auth-internal-status` | диагностика #97 |

Только `IsDevelopment()`. JWT с `iss`/`aud` как у Product (`Perry.AuthService` / `Perry.Client`), claim `role=Admin`.

На фронте (вне этого репо): при `Admin`/`Admin` в DEV вызывается `/api/dev/admin-login`. Users Azure по этому токену **не** откроются — нужен Auth Admin email.
