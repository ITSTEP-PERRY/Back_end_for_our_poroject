# Гайд для студента: как собрать похожий проект (Perry)

Документация этого репозитория — не «свалка отчётов», а **пошаговый учебный путь**:  
как с нуля (или почти с нуля) сделать дипломный маркетплейс с **Product API**, стыком к **Auth**, витриной и мобильным клиентом.

**Доска задач (Trello):** https://trello.com/b/bwEYs3Kq/itstep-perry

Связанные репо:
- Этот бэкенд (Product): https://github.com/Teslyar75/My_Amazon2 · командный https://github.com/ITSTEP-PERRY/Back_end_for_our_poroject  
- Витрина React: https://github.com/ITSTEP-PERRY/perry-front  
- Auth: https://github.com/ITSTEP-PERRY/Backend-client  

Демо: **API `:5272`** + витрина **`:3000`** (+ mobile Expo **`:8081`**).

## Шаг 1 · Пользователи вынести в Auth (микросервис)

**Цель:** Product **не** хранит Users; только `UserId` из JWT.

Сделай:
- login/register/forgot — в Auth Service  
- Product валидирует Bearer (общий секрет / claims)  
- на защите SMTP можно stub (код в логе)  

Читать: [стыки/AUTH-INTEGRATION.md](./стыки/AUTH-INTEGRATION.md) · [стыки/СТЫКИ-МИКРОСЕРВИСОВ.md](./стыки/СТЫКИ-МИКРОСЕРВИСОВ.md) · [стыки/РЕШЕНИЕ-СТЫКОВ-С-КОДОМ.md](./стыки/РЕШЕНИЕ-СТЫКОВ-С-КОДОМ.md)

## Шаг 4 · PostgreSQL + Docker (как у «взрослого» проекта)

**Цель:** одна команда поднять БД (и при желании API).

```bash
cd My_Amazon2
cp .env.example .env
docker compose up -d postgres
dotnet run --project src/Perry.Api --launch-profile http
```

API: http://localhost:5272/swagger · health: `/api/health`

Читать: [инструкции/docker.md](./инструкции/docker.md) · [инструкции/deployment.md](./инструкции/deployment.md) · [инструкции/ci-cd.md](./инструкции/ci-cd.md)
