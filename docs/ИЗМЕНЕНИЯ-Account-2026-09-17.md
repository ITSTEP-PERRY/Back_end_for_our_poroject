## Что сделано

### Frontend (`perry-front`)
- `AccountShell` — сайдбар, breadcrumbs
- `/account/orders`, `/account/wishlist`, `/account/settings`
- Wishlist API + Remove confirm
- Orders + Details modal (статусы Figma)
- Account settings: name / password / email+OTP / logout / delete
- PDP wish list → API

### Backend (`Perry.Api`)
- `GET/POST/DELETE /api/wishlist`
- Миграция `AddWishlistAndOrderShipping` (WishlistItems + order shipping fields)
- `PUT /auth/me`, `PUT /auth/me/password`, `POST/PUT …/email`, `DELETE /auth/me`

- Удалены устаревшие `01`–`33` из корня `docs/screenshots/`
