# Отчёт — #A10 Orders last update

Дата: 2026-09-29  
Ветка: `feature/categories-facets-figma-storefront`  
Trello: [#A10](https://trello.com/c/ZBJZpgnW)

---

## Задача

> Add last update field to Order Entity.  
> Solution: Track last status changes for the order.

---

## Что уже было

| Часть | Состояние до #A10 |
|-------|-------------------|
| `Order.UpdatedAtUtc` | поле в сущности уже существовало |
| `UpdateStatusAsync` | уже писал `UpdatedAtUtc` при смене статуса |
| Admin `GET /api/orders/admin` | уже отдавал `updatedAtUtc` |
| Buyer `Mine` / `ById` | **не** отдавали last update |

Миграция БД **не нужна** — колонка уже в `InitialPostgreSQL` / snapshot.

---

## Что сделано (#A10)

1. **Create order** — при checkout выставляется `UpdatedAtUtc = UtcNow` (стартовое «last update»).
2. **API buyer** (`MapOrder` → `GET /api/orders`, `GET /api/orders/{id}`, checkout response):
   - `createdAtUtc`
   - `completedAtUtc`
   - `updatedAtUtc` — last update
   - `lastUpdateUtc` — тот же timestamp (alias для FE)
3. **API admin** — добавлен alias `lastUpdateUtc` рядом с существующим `updatedAtUtc`.
4. Комментарии в `Order` / `UpdateStatusAsync` — явно #A10 / status change.

## Контракт (фрагмент ответа заказа)

```json
{
  "id": "...",
  "status": "Ordered",
  "orderDateUtc": "...",
  "createdAtUtc": "...",
  "updatedAtUtc": "...",
  "lastUpdateUtc": "...",
  "completedAtUtc": null
}
```

`updatedAtUtc` / `lastUpdateUtc` обновляются при `PUT /api/orders/{id}/status`.

---

## Smoke

```text
POST /api/orders/checkout  → в ответе lastUpdateUtc / updatedAtUtc
GET  /api/orders           → то же у каждого item
PUT  /api/orders/{id}/status  (Admin) → lastUpdateUtc сдвигается
GET  /api/orders/admin     → lastUpdateUtc в items
```
