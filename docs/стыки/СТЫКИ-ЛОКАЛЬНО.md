## Что взять у Влада (#97) — лично, не в чат команды

См. готовый текст: [ЗАПРОС-ВЛАДУ-97.md](./ЗАПРОС-ВЛАДУ-97.md).

1. **`serviceName`** (ожидаем `local-service`)  
2. **`ServiceCredential` plaintext**  
3. Контракт `POST /internal/auth/token`  
4. (опционально) `iss`/`aud`/имена claims — без полного JWT

```env
AuthService__ServiceName=local-service
AuthService__ServiceCredential=<plaintext от Влада>
```

```text
GET http://localhost:5272/api/dev/auth-internal-status
→ credentialConfigured: true, tokenOk: true
```
