# Клиентская часть проекта Perry

Документ фиксирует структуру кода, связанного с **покупателями (клиентами)**.  
Отдельных папок `Client` / `Customer` нет: клиент моделируется как `User` + зоны Account / Cart / Orders.

---

---

## Назначение зон

| Зона | Роль |
|------|------|
| `Domain/Entities` (User*, Cart*, Order*) | Модель данных клиента |
| `Infrastructure/Auth` | Только хеширование пароля, не полный login-flow |
| `Infrastructure/Services` | Бизнес-логика пользователя, корзины, заказов, просмотров |
| `Web/Middleware` | Сессия входа, роли, `?logout=1` |
| `Web/Pages/Account` | Регистрация, логин, профиль |
| `Web/Pages/Cart` | Корзина гостя и пользователя |
| `Web/Pages/Orders` | История заказов, Buy again |
| `Api/Controllers/CartController` | REST для корзины |

---

## Маршруты покупателя

| URL | Страница |
|-----|----------|
| `/Account/Register` | Регистрация |
| `/Account/Login` | Вход |
| `/Account/Profile` | Профиль |
| `/Cart` | Корзина |
| `/Orders` | Список заказов |
| `/Orders/Details/{id}` | Детали заказа |

Админ-зона (`Pages/Admin`, в т.ч. Users) к клиентской UI не относится, но работает с теми же сущностями `User` / `UserAccess`.
